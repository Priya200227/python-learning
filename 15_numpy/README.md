## Why NumPy?

- Stores numerical data in multidimensional arrays.
- Supports vectorized operations, reducing the need for explicit Python loops.
- Provides broadcasting for operations between compatible shapes.
- Includes mathematical and statistical functions.
- Integrates with libraries such as Pandas, Matplotlib, and scikit-learn.

## Learning focus

Understand array dimensions, shapes, data types, indexing, and how operations work across arrays. Practise each concept with small examples before applying it to data analysis.
