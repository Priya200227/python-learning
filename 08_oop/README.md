# 08 - Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming approach where we create and work with objects that contain data and behavior.

In Python, classes act as blueprints for creating objects, while objects are instances of classes.

This section covers the OOP concepts and related Python concepts that I studied through notes, examples, experiments, and code.
